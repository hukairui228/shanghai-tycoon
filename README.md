# 商海浮沉 · 商战

实时商业对战游戏。你在一张等距视角的上海沙盘上，和三位有性格的 AI 大亨（或者你的朋友）同场竞争：抢地、建厂、组生产链，在同一个共享市场里买卖，用商业手段给对手使绊子，最后买下对手的股票，把整家公司吞掉。

每局 7 或 12 分钟，按估值排名或把对手全部收购结束。打赢赚到的钱进你的个人财富，用来升级、买名表豪车豪宅游艇、去澳门玩百家乐、德州扑克和老虎机。

## 玩法

| 系统 | 规则 |
| --- | --- |
| 地图 | 22×22 等距沙盘：黄浦江、东海、城区（陆家嘴、东方明珠）、农田、矿区、油田。资源地块有 1–3 星 |
| 开局 | AI 先选总部，你再选。总部周围若干格内可以占地，地块许可有限，升级总部（花钢材）可以拿更多许可、扩大半径 |
| 生产链 | 农场/油井/矿场只能建在对应资源上；电厂：原油 → 电力；钢厂：矿石+电力 → 钢材；食品厂：粮食+电力 → 食品；芯片厂：矿石+电力 → 芯片；码头提高卖价。城区加工 +15%，地铁上盖 +30% |
| 共享市场 | 所有公司在同一个市场交易。卖得多价格就跌，买得多价格就涨，价格慢慢回归均值。每种资源可以选「自动卖」或「囤货」 |
| 股权收购 | 每家 10 股，第 100 天上市后开放交易。持有对手 5 股即可发起要约收购（按 1.25 倍股价买下其余股份），吞并对方全部产业。自持 5 股免疫 |
| 商业手段 | 组织罢工、工商检查（停工）、舆论危机（股价 -20%）、挖走库存、囤积居奇、恶意倾销、安保合同 |
| 拍卖与事件 | 定期拍卖富矿或地铁上盖地块（不占许可、不限距离）；限电、台风、OPEC 减产、出口管制、降息等事件改变供需，提前一周有传闻 |
| AI 对手 | 王建国（激进）、陈琳达（稳健）、赵海川（投机）、李北辰（圈地）。各有建造偏好、操纵市场、买股收购和商业手段倾向，会在关键时刻喊话 |
| 联机 | 在 claude.ai 里建房间，朋友输入 4 位房间号加入，最多 4 人，空位由 AI 补。房主的页面跑模拟，其他人发指令、收快照 |
| 局外 | 个人财富、等级（15 级称号）、私人收藏、澳门（三个厅，按等级开放）、富豪榜。旧版存档会自动迁移：现金转为个人财富，藏品和等级保留 |

## 代码结构

不要直接改根目录的 `index.html`，它是拼出来的产物：

```bash
vim .src/game/20_engine.js     # 改源码
python3 .src/build.py          # 拼成 index.html
```

`.src/game/` 按文件名顺序拼接：

| 文件 | 内容 |
| --- | --- |
| `00_head.html` | HTML 骨架和全部样式（`:root` 里是配色与字体变量） |
| `10_data.js` | 资源、建筑、总部等级、商业手段、事件、AI 人设与台词 |
| `11_util.js` | 随机数、格式化等工具 |
| `20_engine.js` | 纯逻辑引擎：地图生成、`newMatch`、`step`（推进一天）、`act`（执行指令）、市场、股权、收购、拍卖、事件。不碰 DOM，可以在 node 里跑 |
| `30_ai.js` | AI：选总部、按回报率建造升级、囤货出货、买股收购、回购防守、商业手段、竞拍 |
| `40_portraits.js` | SVG 人物头像生成 |
| `50_render.js` | Canvas 等距渲染：地面、建筑、动画、船、烟、浮字、镜头拖拽缩放 |
| `60_hud.js` | 对局界面：公司卡、市场、操作面板、喊话气泡、拍卖、公司详情、结算 |
| `70_meta.js` | 局外：存档、旧档迁移、办公室主页、收藏、云存档、富豪榜、音效 |
| `75_casino.js` | 澳门：百家乐、老虎机（返还率约 94.7%）、德州扑克 |
| `80_net.js` | 好友联机：大厅、房间、房主广播快照、客户端发指令 |
| `90_boot.js` | 启动 |

旧版源码在 `.src/sec/`，用 `python3 .src/assemble.py` 拼到 `classic/index.html`。

## 测试

```bash
node .src/tests/sim.js 30 normal          # 4 个 AI 无头对打 30 局，看收购次数、胜率分布、建筑结构
python3 -m http.server 8765 &             # 浏览器测试默认访问 127.0.0.1:8765
node .src/tests/solo.mjs                  # 单人整局：开局、选总部、建厂、快进到结算
node .src/tests/multiplayer.mjs           # 两个页面联机：建房、加入、开局、指令同步
node .src/tests/meta.mjs                  # 旧档迁移、收藏、澳门三种玩法
```

浏览器测试需要 Playwright；截图默认写到 `/tmp/shz-shots`（可用 `SHOTS` 环境变量改）。联机测试用 `mockroom.js` 在同一浏览器里模拟 `claude.use('room')`。

页面上留了测试钩子：`__G`（对局状态）、`__R`（渲染器）、`__doAct(cmd)`、`__canClaim`、`__renderAct`。
