# 商海浮沉

单文件网页商业模拟游戏。你在上海开一家贸易公司，在六个港口之间倒卖大宗商品、承接合同、炒 A 股、收藏奢侈品，和 4 家 AI 财团争夺富豪榜，也可以飞去澳门玩百家乐、德州扑克和老虎机。

`index.html` 一份文件跑完全部逻辑：不需要构建、没有依赖、不联网也能玩。接上 DeepSeek 之后，会多出一个看得懂你账本的「AI 智囊」——能回答问题、能照着人话下单、能生成时事和黑天鹅。

在线版（claude.ai，带云存档）：https://claude.ai/artifact/DRRXzfp75RrVdKegdW1ViT

## 文件

| 路径 | 内容 |
| --- | --- |
| `index.html` | 构建产物：整个游戏，HTML + CSS + JS 单文件（约 2400 行 / 200KB） |
| `.src/sec/*` | 源码分片，`00_head.html` 是 HTML 骨架与全部样式，其余 16 个 `.js` 按模块切分 |
| `.src/assemble.py` | 把分片按顺序拼成 `index.html` |
| `.src/smoke.mjs` / `.src/e2e.mjs` | Playwright 自动化测试（冒烟 / 全链路） |
| `saves/save.json` | 存档快照：万和贸易有限公司，第 5398 天，Lv14，净资产约 ¥4136 万 |

## 运行

直接用浏览器打开 `index.html`，或起一个本地服务器（推荐，端口随意）：

```bash
python3 -m http.server 8811
# 打开 http://127.0.0.1:8811/index.html
```

存档在浏览器 localStorage（键名 `shanghai_tycoon_v1`）；在 claude.ai 里运行时才启用云存档与真人排行榜，别处运行时自动跳过。

### 载入存档

`saves/save.json` 的内容就是 localStorage 里那份 JSON：

```js
fetch('saves/save.json').then(r => r.json()).then(s => {
  localStorage.setItem('shanghai_tycoon_v1', JSON.stringify(s));
  location.reload();
});
```

也可以走界面：设置 → 存档 → 导入 / 导出 JSON。

## 改代码的方式

不要直接改 `index.html`，它会被下次拼装覆盖掉：

```bash
vim .src/sec/08_actions.js      # 改分片
python3 .src/assemble.py        # 重新拼装
node .src/e2e.mjs               # 回归测试（需要 8811 端口在跑）
```

分片顺序（也是游戏内的加载顺序）：`00_head` → `01_data` → `02_util` → `03_icons` → `04_state` → `05_fx` → `06_news` → `07_sim` → `08_actions` → `08b_ai` → `09_tutorial` → `10_casino` → `11_persist` → `12_ui` → `12b_views` → `12c_charts` → `12d_events`。

## 这一版加了什么

### 玩法

- **宏观周期**：复苏 / 繁荣 / 过热 / 衰退，每轮 20–40 天自动轮换。周期影响所有商品的价格漂移、波动率和事件倾向——衰退期现金为王，过热期波动放大但机会更多。顶栏会显示当前周期，鼠标悬停看说明和剩余天数。
- **情报系统**：研究部每天产出情报点数（上限 400），可以买三种确定性信息——未公开在途消息（20 点）、某品种 5 日价格展望（35 点）、对手动向（50 点）。花钱换掉不确定性。
- **航运保险**：发船时可选投保，保费是货值的 1.6%，途中跌价或延误赔 80%。长途高波动时值，短途不值。
- **月度财报**：每月最后一天弹出经营回顾，把净资产变动拆成贸易利润 / 股票盈亏 / 澳门净额 / 经营开支 / 利息 / 其他，让你知道钱到底从哪来、到哪去。
- **对手两段式行动**：AI 财团不再随机偷袭——先「起意」（你能从情报里看到苗头），隔几天才「动手」。给自己留了反应窗口。
- **合同议价**：每份合同都能「议价」，用人话提条件（涨价、延期），对方可能接受、可能砍回来、也可能掀桌子走人。
- **一键调货**：交易所第五列直接显示「运到哪个港口能多卖多少」，点一下就把起运港、货物、目的港、装船量填好，跳到航运窗口。
- **亏损预警**：航运窗口在该航线按现价亏损时会明确提示，并给出少装 / 换港口 / 等价三条路，避免闭眼发船。

### AI 智囊（DeepSeek）

设置窗口（快捷键 `S` 或 `?`）里有完整的开关面板：API 密钥、模型（`deepseek-chat` 便宜 / `deepseek-reasoner` 慢但会思考）、AI 时事、对手喊话、演示模式。

上了 key 之后能做六件事：

| 能力 | 说明 |
| --- | --- |
| 顾问咨询 | 把压缩后的游戏状态（现金、库存、在途、行情、宏观、对手）喂给模型，流式返回结论式建议 |
| 自然语言下单 | 「在深圳买 500 吨大豆」「把上海的铜运到鹿特丹」→ 解析成结构化操作 → **先弹确认卡**，你点「确认执行」才真下单 |
| AI 时事 | 按当前市场生成会真正影响价格的财经事件（带品种、方向、持续天数、关联股票） |
| 黑天鹅 | 小概率触发三选一的危机事件，选项各有代价，通过白名单字段改动游戏状态 |
| 合同议价 | 你说条件，模型扮演对方给出 Counter-offer |
| 对手喊话 | 你在扫货时，AI 财团会发表评论 |

安全边界：模型输出只接受白名单字段（`cashPct/prestige/xpPct/intel/debtPct/shipDelay/shock`）并做区间 clamp；密钥只存在本机 localStorage，不上传、不写进存档；所有请求异步非阻塞，不会卡住游戏循环。

**没配 key 也能玩全**：可以打开「演示模式」（内置脚本化回复，不消耗额度）体验完整交互；「下令」在没有 key 时走本地正则解析，一样能下单（支持买 / 卖 / 运 / 股票 / 情报 / 贷款）。

### 界面与操作

- 补齐 `charset` 与 viewport——之前在非 claude.ai 环境打开是满屏乱码，手机端也是错位的。字体改为异步加载，不再阻塞首屏。
- 渲染从「每次刷新重建整块 DOM」改成「建一次 + 增量更新」：文本走 `setTxt`、类名走 `setCls`、图表数据走 `CH` 注册表并按签名跳过无变化重绘、所有 `refresh()` 合帧到同一个 `requestAnimationFrame`。实测单帧（推进一天 + 全量重绘 + 无头浏览器）约 2.5ms。
- 顶栏布局改成可收缩，窗口高度自适应内容，短内容窗口不再留一大片空白。
- 快捷键：`空格` 暂停/继续 · `A` AI 智囊 · `S` 设置 · `M` 静音 · `1–9` 开对应桌面 · `Esc` 关窗口。
- 移动端：顶栏重排、桌面卡片两列、表格可横滑、toast 避让悬浮按钮。

## 代码结构（给编辑者）

- `DATA`：商品、港口、航程、股票、AI 对手、奢侈品、升级项、成就、宏观周期、赌场厅房等配置表
- `SIMULATION`：`tick()` 每个游戏日推进一次——价格、事件、K 线、对手、船只、利息、合同、宏观轮换、情报产出、月度财报
- `ACTIONS`：买卖、发船（含投保）、股票、合同（含议价）、奢侈品、升级、银行、情报
- `AI`（`08b_ai.js`）：DeepSeek 客户端、流式解析、状态压缩、意图解析、事件生成、议价、降级路径
- `CASINO`：百家乐（8 副牌、标准补牌规则）、老虎机（返还率约 94.7%）、德州扑克（蒙特卡洛估胜率的 AI、边池结算）
- `PERSIST`：localStorage 存档；`migrate()` 兼容 v3 老存档（自动补 `macro/intel/rivalIntent/month/ai` 字段，v4）
- `UI` / `VIEWS` / `CHARTS` / `EVENTS`：主页模块、各窗口渲染、图表、事件委托与快捷键

视觉规范写在 `<style>` 顶部的 `:root` 变量里：墨黑底、香槟金细线；A 股习惯，红涨绿跌。

## 自动化测试

```bash
python3 -m http.server 8811 &          # 测试脚本默认访问 127.0.0.1:8811
node .src/smoke.mjs                    # 冒烟：能不能开、有没有报错、有没有乱码
node .src/e2e.mjs                      # 全链路：买货→发船→议价→AI→情报→月报→键盘→性能→移动端
```

`e2e.mjs` 会截图到 `/tmp/shots2/`，最后一屏输出每项 PASS/FAIL、单帧耗时和 DOM 节点数。测试依赖 Playwright（`/Users/a1-6/.workbuddy/binaries/node/workspace/node_modules/playwright`），跑之前确认路径。

页面里还留了几个调试钩子，方便写测试：`__S`（当前 state）、`__nw()`、`__tick()`、`__AI`、`__ui`、`__T`（`open/close/addDay/frame/clearModals/modalText/toast`…）。
